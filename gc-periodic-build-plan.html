The Table

Columns = constitutional layer · Rows = build wave · Select a module

Every module occupies exactly one cell: one layer, one wave. A module may not be built before the modules above it in its own column, and may not be built before its wave opens. The sparse diagonal is the plan — early waves settle the permanent layers, later waves spend them.

Readout

Select any module in the table to read its charter, dependency and exit test.

Permanent · L1–L4

Constitution, semantics, graph, lifecycle. Written once, versioned constitutionally, never refactored casually. Forest — the heritage band.

Surface · L7

The design system itself, built as a ten-step ladder: tokens → colour → type → atoms → molecules → organisms → assemblies → shell → canvas → sovereign.

Active · L5–L11

Capability, journey, cognition, events, data, runtime. Electric — the action and state-transition band. These layers change every release.

Governance · L12

One governance module in every wave without exception. Hazard — no wave closes without its control in place.

Copper · reserved

Copper carries currency and yield only. It appears nowhere in this plan because this plan moves no capital. The restraint is the system working.

Ten Waves

Entry gate · Modules · Exit conditions

A wave is not a sprint. It is a constitutional state transition: the entry gate is a proof obligation, the exit condition is a test another team can run without you. Waves 7 and 8 are the only pair that may run concurrently, and only because they share no layer below L6.
