The mark

The logotype is drawn. R5 · One angle — a box chamfered at the top left and bottom right, with a skylight cut through it that rises straight and turns once, every point on an 11-unit module — replaced the set type on 24 September 2026 (L1-01 §29-0b), exactly as this document said a designed logotype would. GETAWAY is set at 800 and COLLECTIVE at 100. The clearspace, the floor and the device survive unchanged.

Why the corners are cut. RADIUS.none is invariant in this system. A rounded corner would be the only curve in it, on the one element that appears on every page. The chamfer is how a zero-radius system softens a corner, and the mark carries two of them.

Clearspace and the floor

BR-02 defines clearspace as the cap-height of the G. That is only a rule if the cap-height is a number, so it was measured from the font binary this application ships rather than estimated from the drawing.

Getaway Collective
  • 0.727 cap-height as a fraction of font-size — Inter sCapHeight 2048 / unitsPerEm 2816, the master Inter Tight is cut from
  • 32px clearspace at 44px font-size — the cap-height of the G, per BR-02
  • 20px minimum cap-height, which is 27.6px font-size. Below it the wordmark is barred and the device is the only mark
  • 1.25 device edge as a fraction of cap-height — 40px here

Iconography and imagery

Iconography

SPEC  1px stroke, square frame, no fills, no two-tone.

RULE  Glyphs come from the mono type set wherever possible, rather than a separate icon font.

Imagery

SPEC  Architectural. Desaturated 20-30%. Contrast pushed slightly high.

RULE  No lifestyle-stock cliches — no toasting glasses, no staged laughter. Imagery reads like documentation of a place, not an advertisement for one.

₹%↗⌘

BR-03: 1px stroke, square frame, no fills, no two-tone. Glyphs come from the mono set rather than an icon font, which is why these are characters and not drawings.

Voice

Warm is not soft. Assertive is not cold. Confident is not loud.
PrincipleWhat it means in practice
WARMWe speak to a person, not to a form. Peers with shared values, not a counterparty.
CONFIDENTWe state what is true without hedging. No 'may', no 'might', no 'we believe'.
ASSERTIVEEvery sentence says what happens next. We direct, we do not suggest.
PLEASANTCourtesy without softeners. Never curt, never apologetic.

The laws

oneMarkPerSurfaceOne mark per surface. A page carries the wordmark or the monogram, never both — two marks read as two organisations.
theCutIsTheDeviceThe copper skylight is not decoration. BR-01 as amended makes it the brand device, and it is the only place copper carries the brand anywhere in the system.

What is still open

The share card's letters are approximate

The favicon and the iOS icon are now pure geometry, so Satori renders them exactly. The share card also sets the name, and Satori cannot load Inter Tight unless a font file is passed to ImageResponse; none is, so its letters are Satori's default sans. Shipping the binary closes it.

CAP_RATIO is quoted, not measured

next/font fetches Inter Tight at build, so no binary sits in the repository to read. 0.727 is Inter's published ratio; re-read it when a binary is vendored.

The display scale and the stylesheet disagree

constants/typography.ts sets display-xl and display-l at weight 800 and display-m and heading at 300. app/_assemblies/assemblies.css renders all four at 600. That file is generated from GC-ASSEMBLIES.html, so the drift is in the source document, and correcting it restyles every heading on a live platform. Reported, not swept.
